# EcoTrend 🌲

Projeto desenvolvido para a CP de Front-end Design.

Aluno: Bruno Marcelo Real e Silva - RM:569785

## Sobre o projeto

A EcoTrend é uma loja virtual ficticia focada na venda de produtos sustentaveis.

O objetivo do projeto é apresentar uma interface simples e responsiva para um e-commerce.

## Tecnologias utilizadas

- HTML
- CSS
- Bootstrap

## Páginas

- Página inicial
- Produtos e categorias
- Detalhes do produto
- Contato
